**🇫🇷 Présentation**

Multi-Tool est une suite d'outils pour le pentesting, OSINT, réseau, phishing, et plus encore, conçue pour les passionnés de sécurité informatique.  
Ce projet regroupe plusieurs scripts et utilitaires pour faciliter les audits de sécurité et la collecte d’informations.

***⚠️ Usage réservé à des fins éducatives et légales uniquement.***

---

**🇬🇧 About**

Multi-Tool is a toolkit for pentesting, OSINT, networking, phishing, and more, designed for cybersecurity enthusiasts.  
This project gathers multiple scripts and utilities to ease security audits and information gathering.

***⚠️ Use only for educational and legal purposes.***

---

**🇫🇷 Fonctionnalités principales 🛠️**

- 🔍 **OSINT** : Recherche d’informations sur internet, analyse de données publiques et recherches via bases de données.  
- 🌐 **Réseau** : Scans, changement d’adresse MAC, tests de vulnérabilité.  
- 🎣 **Phishing & Social** : Outils d’ingénierie sociale et simulations.  
- 💥 **DDoS & Stress Tests** : Simulations d’attaques pour tests internes.  
- 🧰 **Divers** : Outils utilitaires comme la stéganographie, changement d’IP, etc.

*⚠️ Certains outils nécessitent un environnement virtuel Python (venv) pour fonctionner correctement.
Pense à l’activer avant d’utiliser ces outils.*

---

**🇬🇧 Main Features 🛠️**

- 🔍 **OSINT**: Internet information gathering and public data analysis.  
- 🌐 **Networking**: Scans, MAC address changer, vulnerability tests.  
- 🎣 **Phishing & Social**: Social engineering tools and simulations.  
- 💥 **DDoS & Stress Testing**: Attack simulations for internal testing.  
- 🧰 **Miscellaneous**: Utility tools like steganography, IP changer, etc.

*⚠️ Some tools require a Python virtual environment (venv) to work properly.
Remember to activate it before using those tools.*
